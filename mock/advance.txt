## **1. List Comprehension – 10 Programs**

1. **Square Numbers:** Generate a list of squares of numbers from 1 to 20 using list comprehension.

3. **Odd Numbers:** Generate a list of odd numbers from 1 to 50.

6. **Word Length:** Given a list of words, create a new list containing the length of each word.

7. **Vowels Extraction:** Extract all vowels from a given string using list comprehension.
8. **Nested List Filtering:** Extract numbers greater than 10 from a nested list.
    
   data = [[5, 12, 18], [7, 21, 24], [30, 9, 16]]
    
9. **Common Elements:** Given two lists, create a new list containing only the common elements.
    
   a = [10, 20, 30, 40, 50]b = [20, 40, 60, 80]
    
10. **Prime Numbers:** Generate a list of all prime numbers between 1 and 100 using list comprehension.

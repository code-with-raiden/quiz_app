
## 1. Student Management System

### Scenario

A school wants to store student information. Each student has a name, age, roll number, and marks. The school wants to calculate the student's total and average marks.

### Question

Create a `Student` class that:

1. Uses a constructor to initialize student details.
2. Keeps `name`, `age`, `roll_no`, and `marks` as private attributes.
3. Has an instance method `calculate_total()`.
4. Has an instance method `calculate_average()`.
5. Uses a list to store marks.
6. Uses a loop to calculate the total.
7. Uses `>`, `<`, and `==` operators to check marks.
8. Create two student objects and display their details.

**Concepts:** Encapsulation, private variables, constructor, instance method, list, loop, operators.


## 2. Bank Account

### Scenario

A bank wants a simple system to manage customer accounts. Customers can deposit and withdraw money. The balance should not be directly changed from outside the class.

### Question

Create a `BankAccount` class that:

1. Has private attributes:

   * `__account_number`
   * `__name`
   * `__balance`
2. Uses a constructor.
3. Create `deposit()` as an instance method.
4. Create `withdraw()` as an instance method.
5. Do not allow withdrawal if the amount is greater than the balance.
6. Store transactions in a list.
7. Use a loop to display all transactions.
8. Create a `@staticmethod` to check whether the deposit amount is valid.
9. Create a `@classmethod` to create an account from a string such as:
   `"101-Ravi-5000"`.

**Concepts:** Encapsulation, constructor, private variables, instance method, static method, class method, list, loop, operators.

## 4. Vehicle Rental

### Scenario

A rental company rents cars and bikes to customers.

There are different types of vehicles:

Vehicle
   |
   |-- Car
   |
   |-- Bike


### Question

Create:

* `Vehicle`
* `Car`
* `Bike`

Requirements:

1. `Vehicle` should have private attributes:

   * `__vehicle_number`
   * `__model`
   * `__price_per_day`
2. Use a constructor.
3. Create an instance method `calculate_rent(days)`.
4. `Car` and `Bike` should inherit from `Vehicle`.
5. Override `calculate_rent()` in both classes.
6. Create a static method to check whether the number of rental days is valid.
7. Store rented vehicles in a list.
8. Use a loop to display rented vehicles.
9. Use `>` to find vehicles costing more than ₹1,000 per day.

**Concepts:** Encapsulation, inheritance, constructor, method overriding, instance method, static method, list, loop, operators.
